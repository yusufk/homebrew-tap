# Homebrew Tap — yusufk

Custom [Homebrew](https://brew.sh) tap for my macOS applications.

## Usage

```bash
brew tap yusufk/tap
brew install --cask zoomacit
```

## Available Casks

| Cask | Description |
|------|-------------|
| `zoomacit` | ZoomIt-style screen zoom, draw, and annotation tool for macOS |

## Updating

```bash
brew update
brew upgrade --cask zoomacit
```
